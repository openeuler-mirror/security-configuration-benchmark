### 1.1.14 确保文件、目录权限控制最小化

**级别：** 要求

**检查方式：** Manual

**规则说明：**

按照权限最小化要求，系统中的关键文件，特别是包含有敏感信息的文件，必须设置正确的最小的访问权限，只能有相应权限的用户可以访问，目录也是同样要求。文件或目录权限配置不正确，可能导致包含敏感数据的文件信息泄露，例如访问权限设置为644，任何用户都可以访问；只有root用户需要执行的程序，但却设置了755的权限，导致任何用户都可以执行，引入提权风险。

常见的需要做访问权限控制的文件的建议权限如下：

| 文件名称                         | 设置值           |
| -------------------------------- | ---------------- |
| /etc/passwd                     | 0644（-rw-r--r--） |
| /etc/group                      | 0644（-rw-r--r--） |
| /etc/shadow                      | 0000（----------） |
| /etc/gshadow                      | 0000（----------） |
| /etc/passwd-                      | 0644（-rw-r--r--） |
| /etc/shadow-                      | 0000（----------） |
| /etc/group-                      | 0644（-rw-r--r--） |
| /etc/gshadow-                      | 0000（----------） |
| /etc/ssh/sshd_config               | 0600（-rw-------） |
| /etc/ssh/ssh_host_*_key（SSH私钥文件） | 0600（-rw-------） |
| /etc/ssh/ssh_host_*_key.pub（SSH公钥文件） | 0644（-rw-r--r--） |
| /boot/grub2/grub.cfg（BIOS模式） | 0600（-rw-------） |
| /boot/efi/EFI/openEuler/grub.cfg（UEFI模式） | 0700（-rwx------） |
| /etc/shells                        | 0644（-rw-r--r--） |
| /etc/security/opasswd              | 0600（-rw-------） |
| /var/log/audit/*（审计日志文件）     | 0640（-rw-r-----） |
| /etc/audit/auditd.conf             | 0640（-rw-r-----） |
| /etc/audit/audit.rules             | 0640（-rw-r-----） |
| /etc/audit/rules.d/*               | 0640（-rw-r-----） |
| /usr/sbin/auditctl                 | 0750（-rwxr-x---） |
| /usr/sbin/auditd                   | 0750（-rwxr-x---） |
| /usr/sbin/aureport                 | 0750（-rwxr-x---） |
| /usr/sbin/ausearch                 | 0750（-rwxr-x---） |
| /usr/sbin/autrace                  | 0750（-rwxr-x---） |
| /usr/sbin/augenrules               | 0750（-rwxr-x---） |

| 目录名称                         | 设置值           |
| -------------------------------- | ---------------- |
| /var/log/audit/                    | 0750（drwxr-x---） |

**规则影响：**

- 安全风险：文件或目录权限配置过大（如644、755）可能导致敏感信息泄露或被篡改，例如/etc/shadow权限过大可导致口令哈希被获取。
- 配置影响：权限配置不能过小，如系统配置文件设为600可能导致普通用户无法读取，相应程序因无权读取配置而无法执行。

**检查方法：**

使用ll命令或ls -l命令查看文件权限：

```bash
# ls -l test
-rwxr-sr-t. 1 root root 33 Nov  5 14:44 test
```

**修复方法：**

使用chmod命令修改文件权限：

```bash
# chmod 750 test
# ll test
-rwxr-x---. 1 root root 33 Nov  5 14:44 test
```

**默认值：**

各文件默认权限由系统安装时确定，常见默认值：/etc/passwd 0644、/etc/shadow 0000、/etc/ssh/sshd_config 0600等。
