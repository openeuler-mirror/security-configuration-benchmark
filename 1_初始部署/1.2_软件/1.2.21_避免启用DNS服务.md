### 1.2.21 避免启用DNS服务

**级别：** 建议

**检查方式：** Automated

**规则说明：**

域名系统(DNS)是一种分层命名系统，它将名称映射到计算机、服务和其它联网资源的IP地址。

除非系统被专门指定用作DNS服务器，否则建议禁用DNS Server以减少潜在的攻击面。

**规则影响：**

- 安全风险：非必要的DNS服务增加了系统攻击面，DNS服务可能存在缓存投毒、区域传送等安全风险。
- 配置影响：系统将无法作为域名服务器提供域名解析服务。

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled named
disabled
```

**修复方法：**

不要安装DNS服务（bind）；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove bind
```
或
```bash
# dnf remove bind
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动named服务：

```bash
# systemctl --now disable named
```

**默认值：**

openEuler默认未安装named软件包。
