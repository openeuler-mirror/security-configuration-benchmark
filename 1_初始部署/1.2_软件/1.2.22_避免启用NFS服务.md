### 1.2.22 避免启用NFS服务

**级别：** 建议

**检查方式：** Automated

**规则说明：**

网络文件系统 (NFS) 是 UNIX 环境中最早也是分布最广泛的文件系统之一。它为系统提供了通过网络挂载其他服务器的文件系统的能力。如果系统不导出NFS共享，建议禁用NFS以减少远程攻击面。

**规则影响：**

- 安全风险：NFS服务如果配置不当可能暴露文件系统给未授权用户，增加远程攻击面。
- 配置影响：禁用NFS会影响到系统上依赖NFS的服务和应用程序，以及现有的NFS挂载点。

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled nfs-server
disabled
```

**修复方法：**

不要安装NFS服务（nfs-utils）；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove nfs-utils
```
或
```bash
# dnf remove nfs-utils
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动nfs-server服务：

```bash
# systemctl --now disable nfs-server
```

**默认值：**

openEuler默认未启用nfs-server服务。
