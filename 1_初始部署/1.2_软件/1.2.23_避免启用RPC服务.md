### 1.2.23 避免启用RPC服务

**级别：** 建议

**检查方式：** Automated

**规则说明：**

rpcbind服务将远程过程调用(RPC)服务映射到它们侦听的端口。RPC进程在启动时通知rpcbind，注册它们正在侦听的端口以及它们期望服务的RPC程序编号。然后，客户端系统使用特定的RPC程序号联系服务器上的rpcbind。rpcbind服务将客户端重定向到正确的端口号，以便它可以与请求的服务进行通信。

如果系统不需要基于 rpc 的服务，建议禁用 rpcbind 以减少远程攻击面。

**规则影响：**

- 安全风险：rpcbind服务增加了远程攻击面，攻击者可通过rpcbind获取系统上运行的RPC服务信息，进而针对性攻击。
- 配置影响：依赖RPC的服务（如NFS）将无法正常工作。

**检查方法：**

检查是否启动了服务，如果命令返回为disabled，则表示服务未启动：

```bash
# systemctl is-enabled rpcbind
disabled
```

**修复方法：**

不要安装RPC服务（rpcbind）；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove rpcbind
```
或
```bash
# dnf remove rpcbind
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动rpcbind服务：

```bash
# systemctl --now disable rpcbind
```

**默认值：**

openEuler默认安装rpcbind软件包，但默认未启用rpcbind服务（服务状态为masked）。
