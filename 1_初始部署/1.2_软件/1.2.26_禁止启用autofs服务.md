### 1.2.26 禁止启用autofs服务

**级别：** 要求

**检查方式：** Automated

**规则说明：**

autofs允许自动挂载设备，通常包括 CD/DVD 和 USB 驱动器。启用自动挂载功能后，任何具有物理访问权限的人都可以插入 USB 驱动器或光盘，其内容即可在系统中使用，即使他们本身没有权限来手动挂载该设备。

禁用autofs服务以减少潜在的攻击面。

**规则影响：**

- 安全风险：启用autofs后，任何具有物理访问权限的人都可以插入USB驱动器或光盘自动挂载，即使没有手动挂载权限，可能导致恶意内容被执行或数据泄露。
- 配置影响：系统将不再自动挂载可移动设备，需要手动mount。

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled autofs.service
disabled
```

**修复方法：**

不要安装autofs服务；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove autofs
```
或
```bash
# dnf remove autofs
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动autofs服务：

```bash
# systemctl --now disable autofs.service
```

**默认值：**

openEuler默认未启用autofs服务。
