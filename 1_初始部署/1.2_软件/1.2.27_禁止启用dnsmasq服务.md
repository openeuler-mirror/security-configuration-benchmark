### 1.2.27 禁止启用dnsmasq服务

**级别：** 要求

**检查方式：** Automated

**规则说明：**

dnsmasq是一个轻量级工具，提供 DNS 缓存、DNS 转发以及 DHCP（动态主机配置协议）服务。除非系统被明确指定为DNS缓存、DNS转发和DHCP服务器，否则建议删除该软件包，以减少潜在的攻击面。

**规则影响：**

- 安全风险：dnsmasq历史上存在多个安全漏洞（如DNS缓存投毒、DHCP欺骗），非必要的dnsmasq服务增加了系统攻击面。
- 配置影响：系统将无法提供DNS缓存、DNS转发和DHCP服务。

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled dnsmasq.service
disabled
```

**修复方法：**

不要安装dnsmasq服务；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove dnsmasq
```
或
```bash
# dnf remove dnsmasq
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动dnsmasq服务：

```bash
# systemctl --now disable dnsmasq.service
```

**默认值：**

openEuler默认可能安装dnsmasq软件包，但默认未启用dnsmasq服务。
