### 1.2.31 禁止启用telnet-server服务

**级别：** 要求

**检查方式：** Automated

**规则说明：**

Telnet是一种远程登录协议，以明文方式传输所有数据，包括用户名和口令，容易被网络监听和中间人攻击截获。除非有特殊兼容性需求，否则建议移除Telnet服务端软件包，并使用SSH替代。攻击者可通过嗅探Telnet会话获取系统登录凭证，进而控制整个系统。

openEuler默认未安装telnet软件包。openEuler中telnet包同时包含客户端和服务端（in.telnetd）程序。

**规则影响：**

- 安全风险：Telnet以明文传输所有数据，攻击者可通过嗅探Telnet会话获取系统登录凭证，进而控制整个系统。
- 配置影响：系统将无法对外提供Telnet远程登录服务，可使用SSH替代。

**检查方法：**

- 使用如下命令检查是否安装了telnet软件，如果命令返回为"package telnet is not installed"，表示未安装：

  ```bash
  # rpm -q telnet
  package telnet is not installed
  ```

- 如果telnet已安装，可通过如下命令检查telnet服务是否未启用：

  ```bash
  # systemctl is-enabled telnet.socket
  disabled
  ```

**修复方法：**

不要安装Telnet服务（telnet）；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove telnet
```
或
```bash
# dnf remove telnet
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动telnet服务：

```bash
# systemctl --now disable telnet.socket
```

**默认值：**

openEuler默认未安装telnet软件包。
