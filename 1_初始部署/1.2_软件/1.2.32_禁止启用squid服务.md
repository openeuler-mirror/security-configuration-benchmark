### 1.2.32 禁止启用squid服务

**级别：** 要求

**检查方式：** Automated

**规则说明：**

Squid是一款开源的代理缓存服务器，支持HTTP、HTTPS和FTP等协议的代理与缓存功能。除非系统明确被指定为代理服务器，否则建议移除该软件包，以减少潜在的攻击面。攻击者可利用开放的代理服务隐藏自身地址发起攻击，或通过代理漏洞获取用户访问的敏感信息。

openEuler默认未安装squid软件包。

**规则影响：**

- 安全风险：攻击者可利用开放的代理服务隐藏自身地址发起攻击，或通过代理漏洞获取用户访问的敏感信息。
- 配置影响：系统将无法对外提供代理缓存服务。

**检查方法：**

- 使用如下命令检查是否安装了squid软件，如果命令返回为"package squid is not installed"，表示未安装：

  ```bash
  # rpm -q squid
  package squid is not installed
  ```

- 如果squid已安装，可通过如下命令检查squid服务是否未启用：

  ```bash
  # systemctl is-enabled squid.service
  disabled
  ```

**修复方法：**

不要安装Squid服务；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove squid
```
或
```bash
# dnf remove squid
```

如果业务需要但不需要以服务方式运行，通过以下命令禁止启动squid服务：

```bash
# systemctl --now disable squid.service
```

**默认值：**

openEuler默认未安装squid软件包。
