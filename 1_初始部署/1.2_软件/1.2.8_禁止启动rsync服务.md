### 1.2.8 禁止启动rsync服务

**级别：** 要求

**检查方式：** Automated

**规则说明：**

rsync服务可以用于在服务器之间或者服务器本地不同硬盘分区之间同步数据，但由于rsync使用不加密的传输协议，存在信息泄露的风险。若启用rsync服务，并且在不同服务器之间通过网络传输数据，则攻击者可以通过监听服务器端口或者路由器、交换机数据报文，窃取数据。

openEuler安装镜像中提供了rsync安装包，要求在生产环境中不启动rsync服务。

**规则影响：**

- 安全风险：rsync使用不加密的传输协议，通过网络传输数据时攻击者可以通过监听端口或数据报文窃取数据。
- 配置影响：依赖于rsync服务的程序执行受限制，可通过SFTP等加密协议替代。

**检查方法：**

检查rsync服务是否开启，disabled表示未启用服务，符合规范要求：

```bash
# systemctl is-enabled rsyncd
disabled
```

**修复方法：**

不要安装rsync服务；如果已安装且业务不需要，通过以下命令卸载：

```bash
# yum remove rsync
```
或
```bash
# dnf remove rsync
```

如果业务需要rsync但不需要以守护进程方式运行，通过以下命令禁止启动rsyncd服务：

```bash
# systemctl --now disable rsyncd
```

**默认值：**

openEuler安装镜像中提供rsync安装包，但默认未启用rsyncd服务。
