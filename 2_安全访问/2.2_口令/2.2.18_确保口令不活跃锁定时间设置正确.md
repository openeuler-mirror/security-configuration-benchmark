### 2.2.18 确保口令不活跃锁定时间设置正确

**级别：** 要求

**检查方式：** Automated

**规则说明：**

用户口令过期后，如果在一定时间内未修改口令，该账号应被自动锁定。通过设置口令不活跃锁定时间（INACTIVE），可以防止口令过期后账号仍长期可用，降低被攻击的风险。

建议将不活跃锁定时间设置为不大于30天。

**规则影响：**

- 安全风险：不设置INACTIVE时，口令过期后账号仍可长期使用，降低安全性。
- 配置影响：口令过期超过锁定时间的用户将被锁定，需管理员手动解锁。

**检查方法：**

- 使用如下命令检查系统默认的口令不活跃锁定时间，返回值小于等于30的正数或0（表示口令过期后立即锁定）表示配置正确，-1表示禁用此功能：

  ```bash
  # useradd -D | grep INACTIVE
  INACTIVE=30
  ```

- 检查/etc/shadow中所有有密码用户的第7个字段（口令过期后到账号锁定的天数），返回值大于30或小于0（-1为禁用）表示不合规：

  ```bash
  # awk -F: '($2~/^\$.+\$/) {if($7 > 30 || $7 < 0) print "User: " $1 " INACTIVE: " $7}' /etc/shadow
  ```

**修复方法：**

设置默认的口令不活跃锁定时间：

```bash
# useradd -D -f 30
```

对于已有账号，使用如下命令修改：

```bash
# chage -I 30 <username>
```

**默认值：**

openEuler默认INACTIVE值为-1（禁用不活跃锁定功能）。
