### 2.2.20 确保账号使用影子口令

**级别：** 要求

**检查方式：** Automated

**规则说明：**

影子口令机制将用户口令哈希从/etc/passwd文件移至/etc/shadow文件，/etc/shadow文件仅root用户可读，防止普通用户获取口令哈希后进行暴力破解。所有账号必须使用影子口令。

openEuler默认使用影子口令。

**规则影响：**

- 安全风险：不使用影子口令时，口令哈希存储在所有用户可读的/etc/passwd中，容易被暴力破解。
- 配置影响：无

**检查方法：**

使用如下命令检查/etc/passwd中口令字段是否为x（表示使用影子口令），以下命令应无输出：

```bash
# awk -F: '($2 != "x") {print "User: \"" $1 "\" is not set to shadowed passwords"}' /etc/passwd
```

**修复方法：**

对于未使用影子口令的账号，使用如下命令转换：

```bash
# pwconv
```

**默认值：**

openEuler默认使用影子口令。
