### 2.3.2 确保会话超时时间设置正确

**级别：** 要求

**检查方式：** Automated

**规则说明：**

设置合理的会话超时时间可以降低因管理员人为原因而导致系统被攻击者攻击的风险。

考虑到社区版本在不同场景下的易用性，openEuler发行版默认不配置会话超时时间，请根据实际场景按需配置。建议配置TMOUT为300秒。

**规则影响：**

- 安全风险：不设置会话超时时，管理员离开终端未退出登录，其他人员可直接以管理员权限操作。
- 配置影响：超时时间设置过短会频繁锁定，增加口令输入次数，降低用户体验。

**检查方法：**

```bash
# grep "^export TMOUT" /etc/profile /etc/bashrc ~/.bashrc /etc/profile.d/*.sh
export TMOUT=300
```

**修复方法：**

- 修改/etc/profile文件TMOUT字段，根据业务场景修改为合理的值：

  ```bash
  # vim /etc/profile
  export TMOUT=<seconds>
  ```

- 使用source命令使之生效：

  ```bash
  # source /etc/profile    
  ```

**默认值：**

openEuler默认不配置会话超时时间。
