### 2.3.3 确保Warning Banners包含合理的信息

**级别：** 要求

**检查方式：** Manual

**规则说明：**

Warning Banners包含有系统登录界面添加的警告信息，为所有登录系统的用户标识出本系统的安全警告，安全警告可以根据业务场景包括系统所属的组织，登录行为所受到的监视或者记录，非授权登录或者入侵会受到的法律制裁等内容。不合适的安全警告信息，可能增加系统被攻击的风险，或触犯当地法律法规。
 
Warning Banners不应将系统版本、应用服务器类型、功能等暴露给用户，避免攻击者获取到系统信息，实施攻击。除此之外，还需要正确配置文件所有权，否则未经授权的用户可能会使用不正确或误导性信息来修改文件。

Warning Banners相关文件说明：
- /etc/motd：用户登录成功后显示的提示信息（Message of the Day）
- /etc/issue：本地终端登录前显示的提示信息
- /etc/issue.net：远程登录（SSH等）前显示的提示信息

**规则影响：**

- 安全风险：不合适的安全警告信息可能增加系统被攻击的风险或触犯当地法律法规；暴露系统版本等信息有助于攻击者实施针对性攻击。
- 配置影响：无

**检查方法：**

* 通过cat命令，查看/etc/motd、/etc/issue、/etc/issue.net三个文件中警告信息是否合理，是否存在系统版本、应用服务器类型、功能等信息；

  ```bash
  # cat /etc/motd
  Authorized users only. All activities may be monitored and reported.
  ```

  ```bash
  # cat /etc/issue
  Authorized users only. All activities may be monitored and reported.
  ```

  ```bash
  # cat /etc/issue.net
  Authorized users only. All activities may be monitored and reported.
  ```

* 通过stat命令查看/etc/motd、/etc/issue、/etc/issue.net三个文件权限是否为644，且属主和属组均为root：

  ```bash
  # stat -c "%a %U %G %n" /etc/motd /etc/issue /etc/issue.net
  644 root root /etc/motd
  644 root root /etc/issue
  644 root root /etc/issue.net
  ```

**修复方法：**

* 通过vim命令，修改/etc/motd、/etc/issue、/etc/issue.net三个文件中的告警信息：

  ```bash
  # vim /etc/motd
  # vim /etc/issue
  # vim /etc/issue.net
  ```

  建议添加类似如下的警告信息（根据实际业务场景调整）：

  ```bash
  Authorized users only. All activities may be monitored and reported.
  ```

* 通过chown命令修改/etc/motd、/etc/issue、/etc/issue.net三个文件的属主和属组为root：

  ```bash
  # chown root:root /etc/motd /etc/issue /etc/issue.net
  ```

* 通过chmod命令修改/etc/motd、/etc/issue、/etc/issue.net三个文件的权限为644：

  ```bash
  # chmod 644 /etc/motd /etc/issue /etc/issue.net
  ```

**默认值：**

openEuler默认配置Warning Banners，/etc/issue、/etc/issue.net、/etc/motd内容为"Authorized users only. All activities may be monitored and reported."。
