### 2.4.14 确保用户必须提供密码以进行权限提升

**级别：** 要求

**检查方式：** Automated

**规则说明：**

在sudo配置中，NOPASSWD标记允许用户执行sudo命令时无需输入密码。如果配置了NOPASSWD，则任何获得该用户会话的人都可以直接执行特权操作，增加了系统被未授权操作的风险。sudo配置应确保用户在执行特权命令时必须提供密码进行认证。

**规则影响：**

- 安全风险：配置NOPASSWD时，任何获得该用户会话的人都可以直接执行特权操作，增加未授权操作风险。
- 配置影响：无

**检查方法：**

使用如下命令检查sudo配置中是否使用了NOPASSWD标记，以下命令应无输出：

```bash
# grep -E "NOPASSWD" /etc/sudoers /etc/sudoers.d/*
```

**修复方法：**

检查/etc/sudoers和/etc/sudoers.d/目录下的配置文件，删除包含NOPASSWD标记的配置行，或将NOPASSWD改为PASSWD：

```bash
# vim /etc/sudoers
```

将类似如下配置：

```bash
username ALL=(ALL) NOPASSWD:ALL
```

修改为：

```bash
username ALL=(ALL) PASSWD:ALL
```

**默认值：**

openEuler默认sudo配置未使用NOPASSWD标记。
