### 2.4.4 确保su受限使用

**级别：** 要求

**检查方式：** Automated

**规则说明：**

su命令可以使一个普通用户拥有超级用户或其他用户的权限，它经常被用于从普通用户账号切换到系统root账号。su命令为用户变更身份提供了便捷的途径，但如果不加约束的使用su命令，会给系统带来潜在的风险。通过对用户使用su访问root账号的权限进行限制，仅对部分账号进行su使用授权，可以提高系统账号使用的安全性。

openEuler默认不对su做限制，任何用户均可使用su切换到root。建议通过pam_wheel.so限制仅wheel组用户可使用su。

**规则影响：**

- 安全风险：不加约束地使用su命令，任意用户可切换到root账号，增加系统被未授权操作的风险。
- 配置影响：非wheel组用户无法使用su。

**检查方法：**

- 检查/etc/pam.d/su中是否配置了非wheel组用户账号禁止使用su：

  ```bash
  # grep pam_wheel.so /etc/pam.d/su | grep required
  auth	 required	 pam_wheel.so use_uid
  ```

- 确认wheel组成员仅包含授权用户：

  ```bash
  # grep wheel /etc/group
  wheel:x:10:<user1>,<user2>
  ```

**修复方法：**

- 修改/etc/pam.d/su配置文件，配置非wheel组用户账号禁止使用su：

  ```bash
  # vim /etc/pam.d/su
  auth	 required	 pam_wheel.so use_uid
  ```

- 将需要授权使用su的用户加入wheel组：

  ```bash
  # usermod -aG wheel <username>
  ```

- 从wheel组中移除不应拥有su权限的用户：

  ```bash
  # gpasswd -d <username> wheel
  ```

**默认值：**

openEuler默认不对su做限制（/etc/pam.d/su中未配置pam_wheel.so），任何用户均可使用su切换到root。
