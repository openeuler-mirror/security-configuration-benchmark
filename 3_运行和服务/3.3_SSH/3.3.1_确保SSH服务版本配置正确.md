### 3.3.1 确保SSH服务版本配置正确

**级别：** 要求

**检查方式：** Automated

**规则说明：**

如果使用SSH1，由于协议本身存在较多的未修复漏洞，且社区已不作为主流协议进行长期维护，容易使攻击者有机可乘，造成信息泄露、命令数据篡改等风险。

openEuler默认继承的OpenSSH组件使用SSH协议进行远程控制或在服务器之间传递文件。OpenSSH 7.4及以上版本仅支持SSH协议版本2，SSH1已被完全移除，sshd_config中的Protocol指令已废弃。openEuler默认搭载OpenSSH 8.x及以上版本，无需在sshd_config中配置Protocol字段。

**规则影响：**

- 安全风险：使用SSH1协议容易使攻击者有机可乘，造成信息泄露、命令数据篡改等风险。
- 配置影响：无

**检查方法：**

通过以下命令确认OpenSSH版本，版本不低于7.4即满足要求：

```bash
# ssh -V
OpenSSH_9.6p1, OpenSSL 3.5.8
```

如果版本不低于7.4，则仅支持SSH协议版本2，无需在sshd_config中配置Protocol字段。如果版本低于7.4，检查sshd_config中Protocol字段是否设置为2：

```bash
# grep "^Protocol" /etc/ssh/sshd_config
Protocol 2
```

**修复方法：**

如果OpenSSH版本不低于7.4，无需任何修复，系统默认仅支持SSH协议版本2。

如果版本低于7.4，修改/etc/ssh/sshd_config文件，将Protocol字段后面的数字修改为2，重启sshd服务：

```bash
# vim /etc/ssh/sshd_config
Protocol 2
# systemctl restart sshd
```

**默认值：**

openEuler默认搭载OpenSSH 8.x及以上版本，仅支持SSH协议版本2。
