### 4.1.27 确保setfacl命令的使用被审计

**级别：** 建议

**检查方式：** Automated

**规则说明：**

setfacl命令用于设置文件访问控制列表（ACL），可以绕过传统的文件权限控制。对setfacl命令的成功和失败调用都应记录审计日志，以便事后追溯文件ACL的变更。

openEuler默认不配置此审计规则，建议用户根据实际业务场景配置。

**规则影响：**

- 安全风险：不配置setfacl审计，发生非法修改文件ACL时无法从audit日志中追溯。
- 配置影响：配置审计后，setfacl命令执行时会记录审计日志，对性能有轻微影响。

**检查方法：**

通过如下命令检查setfacl命令的审计规则：

```bash
# auditctl -l | grep setfacl
-a always,exit -F path=/usr/bin/setfacl -F perm=x -F auid>=1000 -F auid!=-1 -F key=privileged
```

**修复方法：**

在/etc/audit/rules.d/目录下新建或修改规则文件，添加审计规则：

```bash
# vim /etc/audit/rules.d/privileged.rules
-a always,exit -F path=/usr/bin/setfacl -F perm=x -F auid>=1000 -F auid!=unset -k privileged
```

使用auditctl -R命令加载规则，使配置生效：

```bash
# auditctl -R /etc/audit/rules.d/privileged.rules
```

**默认值：**

无
