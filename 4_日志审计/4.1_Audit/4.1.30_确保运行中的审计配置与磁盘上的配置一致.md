### 4.1.30 确保运行中的审计配置与磁盘上的配置一致

**级别：** 要求

**检查方式：** Automated

**规则说明：**

审计规则的运行时配置应与磁盘上的配置文件保持一致。如果运行时配置与磁盘配置不同，说明审计规则可能被临时修改，系统重启后规则将恢复为磁盘配置，导致审计规则不一致。

**规则影响：**

- 安全风险：运行时配置与磁盘配置不一致时，系统重启后审计规则会恢复为磁盘配置，可能导致审计规则缺失。
- 配置影响：无。

**检查方法：**

使用如下命令对比运行时配置与磁盘配置是否一致，如果输出包含"No change"表示一致，如果输出"Rules have changed and should be updated"表示不一致：

```bash
# augenrules --check
/usr/sbin/augenrules: No change
```

也可通过diff命令对比运行时配置与磁盘配置：

```bash
# diff <(auditctl -l | grep -v "^No rules") /etc/audit/rules.d/*.rules
```

**修复方法：**

如果运行时配置与磁盘配置不一致，应将磁盘配置加载为运行时配置（auditd不支持通过restart加载新增规则，必须使用augenrules --load）：

```bash
# augenrules --load
```

**默认值：**

无
