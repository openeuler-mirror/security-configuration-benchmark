### 4.1.3 应当配置登录审计规则

**级别：** 建议

**检查方式：** Automated

**规则说明：**

用户成功登录时会在/var/log/lastlog文件中刷新记录，登录失败时会在/var/run/faillock目录中记录失败信息，所以需要对这两个路径进行审计监控，就可以记录用户登录事件。如果不配置登录审计，管理员无法从audit日志中追溯登录事件。

openEuler默认不配置登录审计规则，建议用户根据实际业务场景配置相应规则。

**规则影响：**

- 安全风险：不配置登录审计，发生非法登录行为时无法从audit日志中追溯登录事件。
- 配置影响：配置审计后，登录操作时会记录审计日志，对性能有轻微影响，但由于登录动作本身不应频繁发生，用户无感知。

**检查方法：**

通过执行如下指令，检查用户登录的审计规则：

```bash
# auditctl -l | grep -iE "lastlog|faillock"
-w /var/log/lastlog -p wa -k logins
-w /var/run/faillock -p wa -k logins
```

**修复方法：**

在/etc/audit/rules.d/目录下新建规则文件，例如logins.rules，在文件中添加审计规则：

```bash
# vim /etc/audit/rules.d/logins.rules
-w /var/log/lastlog -p wa -k logins
-w /var/run/faillock -p wa -k logins
```

使用auditctl -R命令加载规则，使配置生效：

```bash
# auditctl -R /etc/audit/rules.d/logins.rules
```

**默认值：**

无
