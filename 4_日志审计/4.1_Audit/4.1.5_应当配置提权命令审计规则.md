### 4.1.5 应当配置提权命令审计规则

**级别：** 建议

**检查方式：** Automated

**规则说明：**

普通用户通过调用提权命令（设置了SUID/SGID）可以获得超级管理员权限，所以提权命令的使用具有较高风险，往往被攻击者利用用于对系统进行攻击行为。

建议对提权命令进行审计监控，以便事后追溯。

openEuler默认不配置提权命令审计规则，建议用户根据实际业务场景配置相应规则。

**规则影响：**

- 安全风险：不配置提权命令审计，攻击者利用提权命令进行攻击时无法从audit日志中追溯。
- 配置影响：配置审计后，使用提权命令时会记录审计日志，对性能有轻微影响，如果业务存在大量、频繁调用提权命令的场景，则可能存在累积效果。

**检查方法：**

使用如下脚本检查提权命令的审计规则：

```bash
#!/bin/bash

array=`df --local -P | awk '{if (NR!=1) print $6}' | xargs -I '{}' find '{}' -xdev -type f \( -perm -4000 -o -perm -2000 \) -print 2>/dev/null | awk '{print $1}'`

for element in ${array[@]}
do
    auditctl -l 2>/dev/null | grep -q "$element "
    if [ $? -ne 0 ]; then
        echo "$element not set"
    fi
done
```

如果系统中提权命令已经配置audit策略，则该脚本执行后无输出；如果未配置，则打印出“\<file path> not set”字样，如下：

```bash
# sh check.sh
/root/test.sh not set
```

**修复方法：**

通过如下方法，查找系统中所有可提权（SUID/SGID）命令，并按照配置格式输出到/etc/audit/rules.d/privileged.rules文件中，此处\<min uid>是/etc/login.defs文件中UID_MIN的值，openEuler上可设置为1000：

```bash
# find / -xdev -type f \( -perm -4000 -o -perm -2000 \) | awk '{print "-a always,exit -F path=" $1 " -F perm=x -F auid>=<min uid> -F auid!=unset -k privileged" }' > /etc/audit/rules.d/privileged.rules
```

使用auditctl -R命令加载规则，使配置生效：

```bash
# auditctl -R /etc/audit/rules.d/privileged.rules
```

**默认值：**

无
